# Car listing sources (Kuwait)

**Last checked: 2026-09-26**

Keep this file current. At the start of a search, if "Last checked" is more than 30 days old, spend a few minutes (at most one WebSearch and a curl probe per new site) looking for new or changed used-car sites in Kuwait. Then update the table and the date. Only list what you actually tested. Never add a site from memory.

The ✅ sites each have a script in `scripts/` (`site_<name>.py`), run together by `search.py`. When a site changes, fix only its script.

**Seller phone (matches duplicates and is shown on the page):** 4Sale has the full number in the list data (`phone`, e.g. 965XXXXXXXX). OpenSooq masks the last 2 digits (`phone_number` "6XXXXXXX" with the last 2 as XX). Motorgy has a `tel:` link on each car page.

| **4Sale** (q84sale.com) | ✅ Main source | `scripts/site_4sale.py`. Pages are Next.js; `__NEXT_DATA__` holds the listings. | **OpenSooq** (kw.opensooq.com) | ✅ Second source | curl `/en/cars/cars-for-sale/<brand>/<model>?page=N`, then `__NEXT_DATA__` → `props.pageProps.serpApiResponse.listings.items`. Fields: `subtitle` (year make model trim), `kilometers_Cars_value_i`, `price_amount` ("4,200 KWD"), `image_uri`, `post_url`. | The list data has only the cover (`image_uri`). The ad page's `gallery.media[].uri` is the ad's own photo list (it matches `imagesCount`); other ads' photos elsewhere on that page are ignored. Full size (1920 px) is the plain path `https://opensooq-imagesv2.os-cdn.com/<uri>`; the `previews/...` sizes are smaller. Link to the ad: `https://kw.opensooq.com/en/search/<id>`. Mostly overlaps with 4Sale; use it to fill gaps (Toyota Highlander, Fortuner). **Its model slugs differ from 4Sale's.** For example, `toyota/fj` works where `fj-cruiser` does not. A wrong slug returns HTTP 410; the valid slugs are in `serpApiResponse.filters.car_model.values[].url_name` on the brand page. |

- 2026-09-26: `site_alsayer.py` reads Car World (Live cars; detail link `/en/<dealership slug>/listing/<slug>`) and Lexus certified (detail link `/en/pre-owned/details/<model>-<id>`, e.g. `ux-4193`).
